# Learner

The global model of what the user knows, shared by every agent in every Operation.
Lines inside the block are managed by `mw.py learner`; don't edit them by hand.

- **level:** new → seen → ok → solid. Two passed checks in a row move up one level; a failed check moves down one.
- **fade:** 0 Watch · 1 Coach · 2 Scaffold · 3 Fade. It follows the same pass/fail rule.
- **review:** the next retrieval-practice date (1, 2, 5, 14 days by level).

## Profile
- Background: learning C in the Lynux-System vault (Learning-C). Linux user (CachyOS, fish shell).
- Goals: learn by building real projects; understand the project's own code well enough to reference it precisely in prompts.
- Preferences: challenges over handed answers in Learn mode; in Model mode, explanations live in Obsidian, not in code comments.
